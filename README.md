# Mission Control Web — Peter's Dashboard

Next.js dashboard for Peter's Executive Assistant duties. Black & white minimalist design with PWA support.

## Quick Start

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- **Dashboard** — 4 duty cards with live status
- **Tasks** — Run duties via Claude Code slash commands
- **Pipeline** — Recharts visualization
- **Calendar** — Duty schedule view
- **Office** — Pixel art Peter animation
- **Settings** — Configuration panel

## Deploy to Vercel

```bash
npm install -g vercel
vercel --prod
```

Or visit [vercel.com/new](https://vercel.com/new) and import this repo.

## PWA Install

After deploying, install as PWA for app-like experience:
- **Desktop**: Click install icon in browser
- **Mobile**: Share → Add to Home Screen
